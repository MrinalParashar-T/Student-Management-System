# Student Management System (Python)

A simple CLI-based Student Management System built using Python.  
This project allows users to manage student records using basic data structures.

## Features
- Add new student records
- View all students
- Search student by ID
- Update student details
- Delete student records

## Tech Used
- Python
- Lists & Dictionaries
- Basic Data Structures

## How to Run
python student_management.py

## Project Description
This project was developed to practice core programming concepts such as data structures, loops, and conditional statements.  
It demonstrates CRUD (Create, Read, Update, Delete) operations in a simple command-line interface.
